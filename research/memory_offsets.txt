============================================
BIẾN QUAN TRỌNG
============================================

1. Zoom
   - Offset: 0xDC
   - Kiểu: float
   - Giá trị mặc định: 32.0
   - Mô tả: Điều khiển khoảng cách camera
   - Sử dụng: Zoom In/Out

2. bFreeCamera
   - Offset: 0x28
   - Kiểu: bool
   - Giá trị mặc định: false
   - Mô tả: Bật/tắt chế độ camera tự do
   - Sử dụng: Free Camera Mode

3. bFreeRotate
   - Offset: 0x29
   - Kiểu: bool
   - Giá trị mặc định: false
   - Mô tả: Bật/tắt xoay camera tự do
   - Sử dụng: Free Rotate Mode

4. m_baseFogEnable
   - Offset: 0x88
   - Kiểu: bool
   - Giá trị mặc định: true
   - Mô tả: Bật/tắt sương mù
   - Sử dụng: No Fog

5. MobaCamera
   - Offset: 0x20
   - Kiểu: Moba_Camera
   - Mô tả: Camera chi tiết trong trận
   - Sử dụng: Camera Control
